# Benchmarks

Public benchmark workflows are organized by input type:

- `references/`: committed FASTA references for included gene/paralog groups.
- `simulation/`: synthetic `dwgsim` read simulations with known read origin.
- `giab/`: public HG002/GIAB SNP-calling benchmark scripts.

Use `demo/` for the smallest end-to-end example. Use `simulation/` when read
origin should be known. Use `giab/` for the public HG002 SNP-calling benchmark.
